# 匿名工作区使用服务端签发凭证

匿名图表和临时资料不再依赖客户端可声明的 `X-Workspace-Id` 作为访问证明。服务端创建匿名工作区并签发高熵不透明凭证，通过 `Secure`、`HttpOnly`、`SameSite` Cookie 交付，数据库只保存凭证哈希；后端从已验证凭证派生所有权范围，并在登录认领时事务化迁移内容和轮换凭证。

## 结果

- workspace ID 只作为内部不透明标识，不能单独授权任何资料访问。
- 图表、资料、证据和读取租约的 API 必须统一经过匿名凭证或登录身份鉴权。
- 现有信任客户端 `X-Workspace-Id` 的路径必须迁移，不能为兼容旧客户端保留绕过入口。
