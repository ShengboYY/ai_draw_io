# 在摄取 worker 内完成上传安全扫描

首版新增独立摄取 worker，并在其中完成文件类型与结构校验、主动内容拒绝和 ClamAV 恶意软件扫描，不启用 GuardDuty Malware Protection for S3。该方案让结构检查、恶意软件扫描和后续解析共用 worker 运行环境及 Fargate 临时存储，避免再增加一套独立安全服务账单，并可并行执行结构检查与恶意软件扫描以降低等待时间；代价是团队负责更新病毒库、限制扫描资源并监控漏扫和超时。

## 结果

- 上传对象在扫描完成前保持隔离，任何扫描失败、超时或不支持状态都按未通过处理，不能继续解析或索引。
- 隔离 bucket 必须启用 object versioning；上传完成时固定具体 `VersionId`，worker 对同一版本完成扫描和复制，不能扫描可被同一上传凭证再次覆盖的“当前对象”。
- worker 必须限制 CPU、内存、临时磁盘、文件展开量和执行时间，且默认禁止不必要的外网访问。
- 扫描器通过内部端口隔离，未来可切换到 AWS 托管或其他引擎而不改变资料状态机。
