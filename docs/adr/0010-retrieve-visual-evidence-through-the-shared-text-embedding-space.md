# 视觉证据通过统一文本 Embedding 空间检索

首版不建立图片向量或图片相似度索引。文本证据直接嵌入；图片、图表和表格先生成受限的结构化视觉描述，并结合标题、邻近正文和 OCR 构成检索文本，再进入同一多语言文本 Embedding 空间。视觉候选命中后回源原始裁剪并按请求需要使用 VLM 核验。该方案统一索引、授权、删除和评测链路，减少实现与成本；代价是视觉召回质量依赖描述质量，不支持图片向图片或相似图搜索。

## 结果

- `VISUAL` 和 `HYBRID` 表示必须核验原始视觉证据，不表示使用图片 embedding。
- 显式单张图片可在当前请求绕过向量候选发现，但仍必须完成安全摄取并建立统一 Pinecone 投影。
- VLM 结构化描述只是可重建检索投影，原始图片/裁剪和业务权限继续保存在 S3/MySQL。
- 如果评测显示视觉 Recall 不达标，应先改进候选识别、描述和有限核验；引入图片向量需新的 ADR 和产品范围确认。
