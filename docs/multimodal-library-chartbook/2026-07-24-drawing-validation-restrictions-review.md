# 2026-07-22 至 2026-07-24 画图与验证限制审查

## 1. 审查范围

本审查基于 2026-07-22 00:00 至 2026-07-24 期间的 Git 历史、当前代码，以及
2026-07-24 尚未提交的工作区改动。重点覆盖：

- 图片转 Draw.io 的运行时限制；
- 资料选择、授权、检索和引用限制；
- 直传图片与检索资料合并后的画布提交限制；
- 上传安全限制在这三天内发生的变化；
- Draw.io/RAG 评测与发布门禁。

上传大小、页数、像素数、加密 PDF、病毒扫描等基础上传限制主要由
`82e22f075` 在 2026-07-19 引入，不属于本次“三天新增”范围；它们在附录中单独列出，
避免误认为是这三天刚加上的。

## 2. 结论

这三天新增的限制并不都是同一类：

1. **应保留的安全边界**：资料授权、版本固定、证据锚点、工具隔离、取消/过期写入保护、
   引用可追踪、XML 安全解析。
2. **应改成系统自动修复的模型输出限制**：轻微坐标越界、可恢复的展示差异。
3. **可能过严的产品策略**：任何低于 `0.75` 的元素都要求确认、任何 50% 几何重叠都拒绝、
   单张图片且仅允许新建、所有功能开关默认关闭。
4. **只用于评测/发布、不应影响用户请求的门禁**：冻结数据集、指标阈值、双人 claim review、
   holdout 暴露后禁止继续调参。

本次已直接修复已经确认的模型输出误判：

- 不超过 `0.10` 的归一化坐标边界漂移会在模型适配器边界裁剪到 `0..1`，
  最终领域对象仍保持严格合法；
- 模型返回坏结构时归类为 `VISUAL_PROVIDER_OUTPUT_INVALID`，不再显示成用户附件无效；
- 不可恢复的坐标（非有限数、与图片完全不相交、非正面积）仍拒绝。

## 4. 本次已修改的错误归因

原流程把下列两类错误都捕获成 `INVALID_VISUAL_INPUT`：

- 用户目标或附件确实不合法；
- 视觉模型返回的 JSON/坐标不满足系统 schema。

这会把系统/provider 的错误显示成“附件无法安全转换”。现在改为：

| 情况 | 新行为 |
|---|---|
| `x/y/width/height` 越界不超过 `0.10`，且仍与图片相交并有正面积 | 裁剪到单位矩形后继续 |
| 模型 JSON、枚举或不可恢复坐标不合法 | `Unavailable(VISUAL_PROVIDER_OUTPUT_INVALID)` |
| 用户声明、附件类型、授权或读取目标不合法 | 仍走明确的 user/input rejection |

最终 `ObservationBounds` 的 `0..1` 约束没有删除；修复发生在不可信模型输出进入领域对象之前。

## 6. 尚未提交的工作区变化

当前还有一个与画布限制直接相关、但尚未提交的改动：

- 新建图表时，如果 candidate 恰好是标准的两个 Draw.io 根 cell（`0` 与 `1`），即使分析器把空画布
  标成 critical，也允许创建；
- 例外只适用于 `USER_CREATE`、数据库中还没有该图、且 XML 精确符合空画布结构。

建议：**保留这个窄例外**。它修复的是“空画布创建被通用质量检查误杀”，没有放开任意无效 XML。
该改动属于用户已有工作区内容，本次修复没有修改或提交它。

同一工作区中的会话清理改动只修复 active routed run 未释放，不新增产品限制。

## 7. 建议的 review 顺序

### 第一批：现在就应调整

1. 轻微坐标越界自动修复、provider 错误不归因用户——**本次已完成**。
2. 50% 几何重叠由硬拒绝改为自动重排。
3. 相同标签/相同关系由硬拒绝改为去重或合并。
4. local profile 默认开启上传、视觉观察和 Direct 转图；生产仍显式开启。

### 第二批：用真实数据校准

1. `0.60` 普通视觉事实阈值；
2. `0.75` 图形元素确认阈值；
3. 资料充分性的 60% 词项重合、2 项/160 字摘要规则；
4. 最多 5 个确认项的选择与剩余项提示。

### 第三批：保持不动

1. 授权、版本 pin、run snapshot、确认 fingerprint；
2. tool-free 视觉 agent 与不可信图片文本隔离；
3. evidenceId、引用和可读性校验；
4. 取消、stale version、原子提交与 XML 外部实体防护；
5. 评测数据冻结、双人 claim review、零未授权引用。

## 附录：三天之前已存在但仍会影响体验的上传限制

这些规则来自 2026-07-19 的 `82e22f075`，不属于本次三天新增：

- 仅接受 PDF、PNG、JPEG；
- 注册用户：PDF 50 MiB、图片 15 MiB、账户原件 2 GiB、并行处理 2、批次 10；
- 匿名用户：PDF 20 MiB、图片 10 MiB、会话临时资料、活跃文件 3、并行处理 1、
  workspace 每小时 10、IP 每小时 30；
- 注册 PDF 最多 200 页，匿名最多 100 页；
- 注册图片最多 25,000,000 像素，匿名最多 20,000,000 像素；
- PDF 解码数据最多 `min(250 MiB, max(20 MiB, 文件大小 × 100))`，对象图最多 100,000；
- 拒绝加密 PDF、多帧图片、声明类型与 magic bytes 不一致、SHA-256/大小不一致和恶意软件。

这些限制整体合理；若要调整体验，优先改善错误文案与本地开发配置，不建议直接取消安全扫描。
